# Portafolio – Juan David González

Sitio estático (HTML, CSS y JS). No requiere instalación.

## Publicar en GitHub Pages
1. Crea un repositorio y sube todo el contenido de esta carpeta (`index.html` en la raíz).
2. En el repositorio: Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
3. En unos minutos estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Pendientes
- Reemplaza `assets/img/perfil.jpg` por tu foto original (la actual es un recorte del diseño).

## Agregar un proyecto
Copia el bloque de Twin Tides dentro de `PROYECTOS` en `js/main.js`, con un `id` nuevo, y pon su imagen en `assets/img/`.
